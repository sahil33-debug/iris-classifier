# 🌸 Iris Flower Classifier

A Machine Learning project that classifies Iris flowers into 3 species with 100% accuracy!

## 📌 Features
- 🤖 Random Forest Classifier with 100% accuracy
- 🌸 Classifies into Setosa, Versicolor and Virginica
- 📊 Feature importance analysis
- 🔍 Predict species from flower measurements

## 🛠️ Tools Used
- Python 3.12
- Pandas
- Scikit-learn
- Matplotlib

## 📊 Model Performance
- Accuracy: 100%
- Most important feature: Petal Length (44%)

## 🚀 How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas scikit-learn matplotlib`
3. Run: `python iris_classifier.py`
4. Enter flower measurements to predict species!
